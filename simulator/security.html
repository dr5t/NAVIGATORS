Security Architecture

Edge-AI Security Model

Navigators IDR is built around the concept of Edge Intelligence. This provides significant security advantages over traditional cloud-based navigation systems.

1. Data Minimization

We do not track, stream, or log your live location to external servers. All processing required to estimate your trajectory is performed directly inside your browser using our WebAssembly-powered ONNX AI model.

2. Offline Operations

Because the application relies heavily on IMU data (accelerometer/gyroscope) rather than external API calls, it functions without an internet connection. Once the OpenStreetMap data is cached locally on your device, you can sever all external network connections and the application will remain fully functional and secure.

3. Transparency

The code governing sensor extraction (`data_recorder.js`) and fusion (`offline_engine.js`) operates transparently in your browser. No obfuscation is applied to the core engine scripts.

4. Web Security Sandboxing

Our application operates entirely within the strict security sandbox of modern web browsers. It requires explicit HTTPS connections to even request access to your sensors, ensuring your data cannot be intercepted via a man-in-the-middle attack during initial loading.
