Cookie and Storage Policy

Last updated: September 2026 · Functional Storage Disclosures

1. Local Storage Technologies

Navigators utilizes local browser storage mechanisms (CacheStorage, IndexedDB, and localStorage) to deliver offline navigation and client-side neural network inference. Navigators does not deploy advertising cookies, tracking pixels, or third-party behavioral analytics scripts.

2. Functional Storage Categories

  • Map Cache (`navigators-map-data-v1`): Stores downloaded OpenStreetMap vector street geometry for offline navigation.
  • Neural Network Model Artifacts: Caches ONNX WebAssembly model weights (`model.onnx`, `norm_stats.json`) for on-device velocity inference.
  • User Preferences & Bookmarks: Persists user-saved places (`navigators_saved_places`), community submissions (`navigators_place_submissions`), and account state (`navigators_user_account`).

3. Managing & Clearing Storage

Users maintain complete control over local data storage. Storage can be audited or purged at any time using the Clear Local Storage action in the Account Profile tab or directly via browser developer settings.
