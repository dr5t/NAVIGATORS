About Navigators

Continuous positioning when GNSS signals stop · SIH26168 IDR Core

System Overview

Navigators is an intelligent dead reckoning navigation system engineered to maintain continuous position accuracy when GNSS signals become unavailable. By combining vehicle IMU motion sensors with a Temporal Convolutional Network (TCN) AI velocity estimator and a 15-state Extended Kalman Filter (EKF), Navigators provides continuous trajectory tracking across tunnels, urban canyons, and denied environments.

Technical Architecture

The core pipeline executes on-device across four integrated modules:

  • 6-DOF IMU Telemetry: Sampled @ 10 Hz for linear acceleration and rotational rates.
  • TCN AI Speed Estimator: Temporal Convolutional Network (559K parameters) executing via ONNX WebAssembly SIMD.
  • 15-State Extended Kalman Filter: Sensor fusion error state update correcting velocity, position, and sensor bias.
  • Geometric Map Matcher: Constrains trajectories to local OpenStreetMap street geometry.
